# 🗺️ Moving from SFMC to Marketing Cloud Next: The Migration Roadmap

Most people are talking about MC Next features. Very few are talking about migration. 

So I created a simple **12-slide roadmap** showing how organizations can move from SFMC to Marketing Cloud Next.

---

### 🤔 What's the biggest challenge in your opinion?

*   **💻 AMPscript?** (Rethinking personalization logic)
*   **🎯 Segmentation?** (Moving from SQL/Filters to Data Cloud UI)
*   **🏗️ Data Model?** (Shifting from Data Extensions to DLOs/DMOs)
*   **🧩 Identity Resolution?** (Configuring matching rules for Unified Profiles)

Let's discuss in the comments below! 👇
