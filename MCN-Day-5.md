# 🧩 Core Data Cloud Components That Power Marketing Cloud Next

Over the last few posts, we've explored what Marketing Cloud Next (MCN) is and why Data Cloud sits at the center of its architecture.

To understand MCN better, it's important to understand the core Data Cloud components that make it possible. These components help transform raw customer data into actionable audiences and personalized experiences.

---

### 🧱 The 5 Core Components

*   **1️⃣ Data Streams**
    Bring data into Data Cloud from various sources such as CRM systems, websites, mobile apps, or external files. Think of them as the entry point for customer data.
*   **2️⃣ Data Lake Objects (DLOs)**
    When data is ingested, it is stored in Data Lake Objects. DLOs preserve the source data and serve as the foundation for further processing.
*   **3️⃣ Data Model Objects (DMOs)**
    DMOs organize data into Salesforce's standardized business model. This makes it easier to understand relationships and use data consistently across the platform.
*   **4️⃣ Segments**
    Segments help marketers identify specific audiences based on attributes, behaviors, and business criteria. 
    *   *Examples:* ✅ Newsletter Subscribers | ✅ Recent Purchasers | ✅ High-Value Customers
*   **5️⃣ Activations**
    Once segments are ready, Activations make those audiences available for engagement across marketing channels. This is where audience insights start turning into customer experiences.

---

### ⛓️ Data Flow

```text
Data Streams ➔ DLOs ➔ DMOs ➔ Segments ➔ Activations ➔ Marketing Cloud Next Engagement

```

💡 Key Takeaway
While MCN is the engagement layer, Data Cloud provides the foundation. Understanding Data Streams, DLOs, DMOs, Segments, and Activations is essential because these are the building blocks that power customer experiences in Marketing Cloud Next.
